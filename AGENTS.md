# AGENTS.md — Project Health Command Hub demo

This repository is a **mock-data Angular wireframe** for a construction portfolio health hub.

## Non-negotiables
- Mock/stub data only — no live APIs, secrets, or production URLs
- Keep DEMO banner visible
- Prefer decision-oriented UX over visual polish
- Update `docs/inputs/` when journeys/scope change

## Layout
- `docs/inputs/` — example customer intake package
- `docs/10-cursor-components-for-repeatable-prototypes.md` — skills/rules/hooks/commands/Automations guide
- Angular app (to be added by Cloud Agent) — clickable prototype for journeys J1–J3

## Surfaces
Humans operate via Agents Window / cursor.com/agents / Automations — not a classic IDE requirement for this demo narrative.
