# Input templates (blank)

Blank intake forms. Fill these offline or in a workshop; or skip them and use [`framework/prompts/00-main-intake.md`](../../prompts/00-main-intake.md) in Agents Window / Cloud Agents.

A filled customer package belongs under `apps/<slug>/docs/inputs/`. Flow specs belong under `apps/<slug>/docs/flows/` (see [`flow-spec.md`](flow-spec.md)).

| Path | Use |
| --- | --- |
| `apps/examples/project-health/docs/inputs/` | Filled **example** (Project Health demo) |
| `framework/inputs/templates/` | **Blank** copies of the same structure |
| `framework/prompts/00-main-intake.md` | Agent-led interview (preferred in Cursor) |

Replace every `_[…]_` placeholder. Do not put real secrets, PHI, or production URLs in the repo.
