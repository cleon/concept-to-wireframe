# EXAMPLE — Information architecture / screen inventory

## Nav
1. **Portfolio** (default) — list + filters + health badges
2. **Project detail** — summary strip + tabs: Overview | Schedule | Cost | Safety | Change
3. **Issue / driver detail** (drawer or page) — single driver with stub timeline
4. **About / prototype banner** — clearly labels DEMO / mock data

## Portfolio screen
- Filters: region, business unit, health
- Table or cards: name, health, schedule SPI stub, cost CPI stub, open critical count, last updated (mock)
- CTA: Open project

## Project Overview
- Health badge + one-line narrative (stub)
- Driver chips with severity
- "Needs steer" toggle (client-side mock)
- Top 3 issues list

## Schedule / Cost / Safety / Change tabs
- KPI strip (stub)
- List of issues/drivers
- Link into driver detail

## Non-visual requirements
- Decision-oriented copy (verbs: escalate, review, acknowledge)
- Not a marketing mock—dense enough for PM testing
- Responsive desktop-first (1280+); tablet OK; mobile not required
