# Feasibility readout

## When

Walkthrough or Slack triage notes exist. Someone asked “can we build Phase 1?”

## Do

1. Read `docs/inputs/06-source-system-map.md`, `08-feasibility-questions.md`, `09-success-metrics.md`.
2. Map notes onto the six feasibility questions. Mark answered vs still open.
3. Recommend **two** Phase-1 integration domains (not all four) and name the join-key / stewardship risks.
4. Separate: UX validated on stubs vs. claims that need real data.
5. Write a one-page readout. Optionally append unanswered items to `08-feasibility-questions.md`.

## Guardrails

- A pretty wireframe is not evidence that P6 or ERP integration is easy.
- Do not open a production repo or add connectors.
- If notes are vague, list the missing scorecard items instead of a fake green light.
