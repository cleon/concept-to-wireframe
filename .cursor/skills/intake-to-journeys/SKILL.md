# Intake → journeys

## When

A human dropped or updated `docs/inputs/` and wants a ranked prototype set (max 3 in-app journeys).

## Do

1. Read `docs/inputs/00-README.md` through `03-priority-journeys.md`, plus personas and the concept brief.
2. List candidate journeys as **Trigger → steps → Decision → Good enough**.
3. Rank three for the wireframe (P0/P1). Everything else goes under **Deferred**.
4. Check each in-app journey against `04-ia-and-screens.md`. Note screen gaps.
5. Write or replace `docs/inputs/03-priority-journeys.md`. Do not implement UI in this skill.

## Guardrails

- Prefer decisions a Portfolio Director or PM can finish without a facilitator.
- Do not add live-integration journeys.
- If intake is thin, ask for the missing persona decision — do not invent a fourth in-app journey.
