# Input templates (blank)

Blank intake forms matching `docs/inputs/` examples. Fill these offline or in a workshop; or skip them and use `docs/prompts/00-main-intake.md` in Agents Window / Cloud Agents.

| Path | Use |
| --- | --- |
| `docs/inputs/` | Filled **examples** (Project Health demo) |
| `docs/inputs/templates/` | **Blank** copies of the same structure |
| `docs/prompts/00-main-intake.md` | Agent-led interview (preferred in Cursor) |

Replace every `_[…]_` placeholder. Do not put real secrets, PHI, or production URLs in the repo.
