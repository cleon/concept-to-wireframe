# EXAMPLE — Priority use journeys (prototype set)

Ranked to **3** for the wireframe. Others deferred.

## J1 — Portfolio morning scan → escalate (P0)
**Trigger:** Portfolio Director opens hub at start of day  
**Steps:** See ranked projects by health → filter by region/business unit → open a red project summary → mark "needs steer" / add note  
**Decision:** Which 1–3 projects get attention today  
**Good enough:** Heat/list readable; red/amber/green consistent; two clicks to "why"

## J2 — Project deep-dive: why is this red? (P0)
**Trigger:** PM or Director opens a red project  
**Steps:** Health summary → driver breakdown (schedule / cost / safety / change) → open top driver detail → see recommended next action (stub)  
**Decision:** Root driver to act on; whether to escalate  
**Good enough:** Driver mix visible; believable stub metrics; empty state if a domain has no issues

## J3 — Functional lead review path (P1)
**Trigger:** Cost Lead opens hub from Slack link to a project  
**Steps:** Land on project → jump to Cost tab → review variance & contingency → leave review flag for PM  
**Decision:** Cost story credible / needs follow-up  
**Good enough:** Cost tab decision-oriented; flag persists in mock session state
